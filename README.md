# Hi, I'm Peter 👋

Full-stack web developer. I build things for the web, front to back: Drupal sites, Vue applications, REST APIs, and the tooling that holds it all together. I like things robust and good at handling problems gracefully, and I sweat the details of the experience everywhere: the UI, the docs, even what a script prints to the terminal.

I've been at it since the Atari ST days (BASIC first, then static HTML sites) and professionally since 2000. I've been at Kellett Communications since 2006, where I'm the senior technical lead for a small team working across Drupal and Laravel. I've also been part of the Drupal community for 17+ years.
